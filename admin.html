This panel supports both the existing Primary CSV format and the new Middle / High / Higher Secondary format.

Question CSV uploader

Old format (14 columns):

id,subject,category,topic,level,difficulty,question,opt1,opt2,opt3,opt4,correctIndex,explanation,hint

New format (16 columns):

id,level,subject,topic_id,subtopic_id,category,topic,difficulty,question,opt1,opt2,opt3,opt4,correctIndex,explanation,hint

Old-format files continue to work; their topic_id and subtopic_id remain NULL. New-format files must use the agreed stable IDs. Maximum 500 questions and 2 MB per import. Existing records are never overwritten.
